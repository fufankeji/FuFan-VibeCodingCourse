## 2. 信息架构对比（深入选 5 个）

### 2.1 同花顺
- **底部 4-Tab**：自选 / 行情 / 资讯 / 交易
- **自选页**：下拉切换"自选股 / 最近浏览 / 自选分组"；2025-11 个股页加了左侧迷你分时图列表，左右联动切自选
- **AI 入口**：首页顶部 + 资讯 Tab 嵌入"问财"对话框

### 2.2 东方财富
- **底部 5-Tab**：首页 / 行情 / 交易 / 财富号 / 我的（自选股置于行情顶部子 Tab）
- 顶部整合行情/资讯/社区，"自选签置顶"

### 2.3 雪球

### 2.4 富途牛牛

## 3. 交互模式：自选股 / 智能选股 / 异动推送

### 3.1 自选股管理（业内套路）
- **多端云同步**：同花顺、东方财富、富途均默认开启
- **分组 + 动态分组**：同花顺支持"按策略自动更新股票池"的动态分组；富途分组 + 个性化报价模式
- **批量管理**：批量加入 / 删除 / 移动分组 / 一键买入（东方财富）
- **上限**：富途明确 2000 只；其它多在 1000–2000 区间
- **新趋势**：自选与个股页"左右联动"（同花顺 2025-11 迷你分时图列表）

### 3.2 智能选股（业内套路）
- **条件式选股器**：传统 GUI 表单（市值、PE、ROE、技术指标…），主流仍为通达信、东方财富选股器
- **自然语言选股**：同花顺问财 / 东方财富妙想 / AI 涨乐
  - 例："均线多头排列""低估值高股息的科技股""科创板研发投入超 20%"
  - 后台 Agent 解析 → 转量化条件 → 出列表
  - 同花顺问财 2024-04 已切多 Agent 自主规划，对话句数从 5.1 → 8.6
- **策略保存与回测**：问财可一键生成 Python 脚本 / 回测；AI 涨乐"任务助手"可一句话封装回测
- **API 化**：问财有 `pywencai` 库可调

### 3.3 异动推送（业内套路）
- **价格 / 量能阈值**：基础款，所有产品都有（涨跌幅、振幅、量比突破）
- **智能盯盘**：同花顺、AI 涨乐、富途均冠以此名，本质是"多条件 + 用户偏好"过滤
- **资金流向异动**：主力流入流出、北向、ETF 申购（AI 涨乐"资金涨停猎手"）
- **事件驱动**：研报 / 公告 / 政策（财联社主打，10 秒级）
- **AI 解释型推送**：不仅推"X 涨停"，还附"为什么"（产业链知识图谱）
- **多渠道分发**：APP push 为主，部分支持微信服务号 / 短信，B 端有飞书机器人

## 4. AI 化案例（至少 4 个）

### 4.1 同花顺问财（iWenCai）
- **形态**：对话式选股 / 诊股 / 问股，All-in-one 搜索框
- **底层**：自研 HithinkGPT（7B~130B 多档），多 Agent 协作
- **能力**：自然语言 → 量化条件 → 股票列表 → 可一键转 Python / 回测；R1 级深度推理 + 知识图谱
- **成熟度**：商业化最早（产品已多年），人均问句数 8.6（大模型版本上线后）
- 来源：[woshipm 互金 AI 对决](https://www.woshipm.com/ai/6196219.html)、[腾讯新闻 Agent 战略](https://news.qq.com/rain/a/20250724A04WA000)、iwencai.com

### 4.2 东方财富妙想
- **形态**：独立 AI 入口（ai.eastmoney.com）+ App 内 AI Tab；对话 + 卡片
- **能力**：覆盖热点追踪 / 选股择时 / 标的诊断 / 下单交易全流程；选股维度最丰富（A/港/美），支持财务、技术信号、主营业务、主要产品筛选
- **数据**：宣称 2 亿+资讯舆情、4 亿+宏观、6 亿+行业、10 亿+企业、百亿+市场+股吧
- **里程碑**：2025-03-21 全量开放 App
- 来源：[东财财富号官宣](https://caifuhao.eastmoney.com/news/20250322080557397117600)、[选股案例](https://caifuhao.eastmoney.com/news/20250705102944078746110)

### 4.3 AI 涨乐（华泰）
- **形态**：**AI 原生 App**（不是在老 App 上加 AI），LUI + GUI 双驱动
- **三大工作区**（2026-01 优化版）：早点听（个性化音频简报）/ 特别提醒（事件级推送）/ 任务助手（一句话封装流程）
- **底层**：多专家 Agent 协作（宏观/产业链/技术/财报），三层记忆体系（短/中/长期知识图谱）
- **数据表现**：上线百日 240 万用户、月活环比 +15%
- 来源：[51CTO 发布报道](https://www.51cto.com/article/827884.html)、[新华网 21 经济报道](https://js.news.cn/20260127/88de80e009a9403fbe088581a20b960c/c.html)

### 4.4 广发易淘金 + 天玑智融
- **形态**：在老 App 增量上线 AI 原生版，引入"天玑智融"大模型
- **新模块**：i 盯盘、i 复盘
- **特点**：集成约 30 款"智能"工具，相对偏功能堆叠（不及 AI 涨乐重构彻底）

### 4.5 FinGPT（开源对照参考）
- AI4Finance Foundation 开源，[github.com/AI4Finance-Foundation/FinGPT](https://github.com/AI4Finance-Foundation/FinGPT)
- 2024-12 论文《FinGPT: Enhancing Sentiment-Based Stock Movement Prediction》(BA 案例 HG-NC 准确率 63.2%)
- 提供 Forecaster 工具：股票代码+日期 → 一周走势预测
- 我们做技术选型时的开源参考，**不是直接竞品**

### 成熟度排序（主观判断，仅 A 股 AI 选股/盯盘）
问财 ≈ 妙想 > AI 涨乐（新但路线最激进）> 易淘金/天玑智融 > 其它券商加 AI 的"工具堆叠"

## 5. 推送形态（至少 3 种）

### 5.1 APP 原生 Push（移动推送）
- **代表**：同花顺智能盯盘、东方财富自选股动态、富途智能盯盘、AI 涨乐"特别提醒"
- **格式**：
  - 标题：`异动预警：贵州茅台放量突破`
  - 正文：`5 日均量放大 2 倍，当前价 XXX（+X.X%）`
  - Action：点击跳转个股页 / 二次确认 / 设置提醒
- **节奏**：盘中实时（延迟 <1 分钟），盘后总结
- **优点**：实时、原生；**缺点**：信息密度有限、容易被关通知
- 来源：[Pushwoosh 金融推送基准 2025](https://www.pushwoosh.com/zh/blog/fintech-push-notifications/)（金融行业 push opt-in 率行业领先）

### 5.2 微信公众号 / 服务号模板消息 + 小程序
- **代表**：财经早餐类公众号、券商服务号
- **典型早盘简报格式**：
  ```
  【A 股早盘简报】2026-XX-XX
  市场概览：上证 XXX 点（+X%）
  板块异动：新能源、半导体领涨
  重点股票：XXX（600XXX）量比 X.X
  点击查看完整分析 →（小程序 / H5）
  ```
- **节奏**：盘前 9:15–9:25 固定推送
- **优点**：图文丰富、可深链小程序；**缺点**：依赖微信生态，推送频次受限
- 来源：[腾讯云 异动推送实践](https://cloud.tencent.com/developer/article/2659681)、[帆软 案例](https://www.fanruan.com/blog/article/349344/)

### 5.3 飞书 / 钉钉机器人 Webhook（B 端 / 团队盯盘）
- **代表**：自建量化盯盘脚本、机构内部使用
- **格式**：纯文本 + emoji，或富文本卡片，支持 @全体
- **示例代码**（业内常见 Python）：
  ```python
  payload = {"msg_type": "text", "content": f"【异动】{code}\n涨幅:{chg}%\n量比:{vr}"}
  requests.post(webhook_url, json=payload)
  ```
- **节奏**：实时、条件触发
- **优点**：团队协作场景天然适配、零门槛接入；**缺点**：C 端不普及
- 来源：[CSDN 飞书盯盘实践](https://adg.csdn.net/694cf5515b9f5f31781aaa5e.html)

### 5.4 (Bonus) 音频简报
- **代表**：AI 涨乐"早点听"
- **形态**：基于用户持仓 / 自选生成 8–10 分钟个性化音频，盘前 / 盘中 / 盘后三档
- **价值**：通勤场景、零屏幕时间获取信息
- 来源：[腾讯新闻 AI 涨乐 早点听](https://news.qq.com/rain/a/20260203A06VUG00)

### 5.5 (Bonus) 7×24 滚动电报流
- **代表**：财联社电报（[m.cls.cn](https://m.cls.cn/index)）
- **形态**：app 内独立 Tab，秒级滚动，条目极短（一两句话），重要的红色高亮
- **价值**：极高时效性，资讯类用户黏性强

## 6. 对我们的启发（结论先行）

我们要做"7×24 帮用户盯 A 股的 AI 助手"，三条路要分别选：

### 6.1 信息架构：抄 **AI 涨乐 + 富途** 的混合
- **开屏即 Dashboard / 自选**：富途模式，用户打开就看到自己关心的东西，不要再让他翻 Tab
- **底部 LUI 全局输入框**：AI 涨乐模式，自然语言指令永远 1 tap 可达（这是我们作为 AI 产品的根本差异化）
- **顶部卡片化 GUI**：行情 / 持仓 / 自选 / 简报 可拖拽配置（参考 AI 涨乐"上半屏卡片化"）
- **避免**：同花顺/东方财富那种"5 Tab + 几十个二级入口"的工具堆叠路线 —— 我们做的是 AI 助手，不是行情大全

### 6.2 推送形态：APP push + 微信服务号 + 飞书机器人 三路齐发
- **APP push** 做主通道（实时异动）
- **微信服务号模板消息** 做早盘简报（盘前 9:15 固定推送、富文本、深链小程序看完整版）
- **飞书机器人 Webhook** 做"高级 / 工作室"用户的可选通道（B2C 量化爱好者刚需）
- **可借鉴**：AI 涨乐"早点听"音频简报形态作为差异化加分项（不是 MVP，二期）
- **可借鉴**：财联社的"条目极短 + 关键词高亮" 文案风格
- **三档节奏**：盘前简报（9:15）/ 盘中实时异动（<1min）/ 盘后小结（15:30）

### 6.3 AI 交互：抄 **问财 + AI 涨乐** 的组合
- **自然语言选股**：抄问财（已被市场验证、用户 mental model 成熟）
  - 关键能力：自然语言 → 条件解析 → 列表 → 一键加入自选 / 设置盯盘
  - 必须支持模糊查询（"低估值高股息的科技股"这种）
- **AI 解释型推送**：抄 AI 涨乐"特别提醒"
  - 不止推"X 涨停"，还推"为什么"（产业链知识图谱 / 关联事件）
  - 这是 AI 产品对传统盯盘 App 的核心降维点
- **多 Agent 架构**：参考问财（宏观 / 技术面 / 财报 / 情绪 各一个专家 Agent）+ 主 Agent 调度
- **任务助手**：抄 AI 涨乐"一句话封装"思路 — 用户说"跟踪光伏政策"，AI 自动建分组、设异动规则、订阅相关研报

### 6.4 必须避免的坑
- 不要做"AI 套壳"：在老 App 顶部加个对话框，问什么都答"请去查行情" — 易淘金的反例
- 不要做"工具堆叠"：30 个智能工具列表，用户记不住 — 易淘金的另一面
- 不要无视券商合规：我们如果不持牌，不能做"下单"，最多做到"加入自选 + 推送 + 跳转券商 App"
