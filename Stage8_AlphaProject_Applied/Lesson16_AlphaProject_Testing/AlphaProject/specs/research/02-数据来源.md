## 0 · TL;DR（产品立项一句话）

**最稳妥的个人开发者方案 = Tushare Pro（500 元/年）做骨干历史+财务+日线 + AkShare（免费）做实时快照与板块异动 + miniQMT（券商免费、≥10 万门槛）做真实时五档/Tick 推送与下单**，三件套总成本 = 500 元 + 一个能开 miniQMT 的券商账户，覆盖 7×24 盯盘 App 95% 的数据需求。

只有当后续要做"个人商用 SaaS"或"对外卖榜单/简报"时，才需要升级到 **JoinQuant SVIP（2,799 元/年）** 或 **东方财富 Choice（≥5,800 元/年）** 取得合规授权；Wind/iFinD 个人完全不推荐。

## 1 · 全市场盘点：A 股行情数据，能怎么拿？

按"个人开发者拿数据"的实际路径，A 股行情数据来源可以分成 6 大类：

| 类别 | 代表渠道 | 本质 |
|---|---|---|
| **① 开源聚合 API（Token/免费）** | Tushare Pro、AkShare、baostock、efinance | 第三方对官方/网站做了清洗与统一封装 |
| **② 云端量化平台** | JoinQuant 聚宽、RiceQuant 米筐、掘金量化 GM | 自带数据 + 回测 + 策略托管 |
| **③ 机构终端 + API** | Wind（万得）、同花顺 iFinD、东方财富 Choice | 专业终端 + 量化 API，机构定价 |
| **④ 券商直连 / 实盘量化客户端** | 迅投 QMT / MiniQMT、恒生 PTrade、华泰 MATIC、国君 FATS | 持牌券商提供，含 Level-1/L2 推送 + 下单 |
| **⑤ 财经网站非官方接口/爬虫** | 新浪 hq.sinajs.cn、腾讯 qt.gtimg.cn、东方财富 push2、雪球 pysnowball、easyquotation | 无官方契约、灰色地带 |
| **⑥ 港美股 / 海外** | yfinance、富途 OpenAPI、老虎 OpenAPI、Polygon、IEX | 海外合规通道，配合 A 股做"全市场"视图 |

- **直接对接交易所行情专线 / 上证所信息网络**：仅卖给持牌机构，个人无门。

## 4 · 本项目（7×24 盯盘 AI 助手）的推荐方案

### 4.1 推荐主方案 · "三件套"

```
┌──────────────────────────────────────────────────────┐
│  数据层 v1（个人立项阶段，总成本 ≈ 500 元/年）       │
├──────────────────────────────────────────────────────┤
│  历史 + 财务 + 因子    →  Tushare Pro（5000 积分档）  │
│  实时快照 + 板块 + 异动 →  AkShare（免费）            │
│  实时五档/Tick + 下单   →  MiniQMT（10 万门槛券商）   │
│  港美股补充            →  yfinance（仅个人测试）/富途 │
└──────────────────────────────────────────────────────┘
```

**理由：**

1. **Tushare 5000 分**：500 元/年拿到 500 次/分 + 常规接口无总量上限，**早盘简报、自选股财务面板、回测全部满足**；接口结构稳定 = AI 写 SQL/调用层时 prompt 工程成本最低。
2. **AkShare**：实时 spot、板块涨幅榜、龙虎榜、资金流、雪球热度等"广度数据"全有，**异动预警引擎**主要靠它。代码 MIT 协议，App 自己用没问题。
3. **MiniQMT**：A 股个人能合规拿到的**唯一实时五档+逐笔推送**渠道，自带下单能力，将来要做"一键打板/预警直接下单"是必须的。**注意：必须开 10 万+ 的券商账户**（国金/国信/华西/国盛等），这是产品定位"重度用户"的硬门槛。
4. 港美股 v1 阶段不做实时，仅用 yfinance 做日线信息卡。

### 4.2 备用切换方案

| 触发条件 | 切到 |
|---|---|
| Tushare 限频不够（用户量起来后） | 升级到 10000 分（1,000 元/年）+ 分钟实时订阅（1,000 元/月） |
| AkShare 上游被东财封 / 实时数据不稳定 | 切 efinance 或腾讯 qt.gtimg.cn 做秒级快照备份；中长期切 Tushare 实时分钟 |
| 要做"云端策略托管 + 多用户分享" | 加 **JoinQuant SVIP 2,799 元/年** 或迁到米筐 Workspace |
| 要做对外 SaaS / 商用 | 必须采购 **Choice 标准版 5,800-18,000 元/年** 或谈 Tushare 机构（5,000 元/年起） |
| 用户要 Level-2 深度行情 | **没有便宜路径**：要么用户自己开 QMT 拿券商 L2，要么走上证所信息网络（机构） |
| 港股要实时 | 接入富途 OpenD（L2 ≈ 60 HKD/月，最便宜） |

### 4.3 风险点（务必在立项时识别）

1. **协议风险 - 商用边界**
   - Tushare Pro 协议明确"非商业化"，个人 App 自用 = 灰度可行；**对外卖订阅 = 违约**。
   - AkShare 数据继承上游 ToS，**对外商用必须替换为 Choice 等持牌数据**。
   - efinance 明确禁商，**不要在生产环境用**。
   - 雪球/新浪/腾讯爬虫：**任何对外商用 = 高法律风险**（《反不正当竞争法》案例已多）。

2. **稳定性风险**
   - AkShare 上游 2025-04 起被东财限流升级、2026-03 进一步合规整改；架构上必须做**降级 fallback**：AkShare → efinance → Tushare 实时分钟。
   - MiniQMT 依赖券商客户端，券商升级/熔断都会导致策略停摆，需要**心跳监控 + 自动重连**。

3. **门槛风险**
   - MiniQMT 10 万门槛会过滤掉 60%+ 潜在用户；产品定位上需要明确："轻度用户用 Tushare+AkShare 看盘+预警，重度用户接 MiniQMT 实盘"。
   - 学生/校友通道（Tushare 高校免费、Choice 高校版）是早期获客和测试的**重要冷启动入口**，建议产品里专门做一个"学生认证"。

4. **数据质量风险**
   - AkShare 实时 spot 在交易高峰偶发返回空/历史值，需要**双数据源校验**（与 Tushare 实时 / 腾讯 qt 交叉）。
   - Level-2 在 v1 不做，避免被深交所/上交所信息网络合规追问。

5. **成本拐点**
   - 用户量 < 1000：500 元/年 + 一个 100 元/月 ECS 即可。
   - 用户量 1000-1 万：必须升级 Tushare 实时分钟（1000 元/月）+ 多 IP 抓 AkShare，预算 ≈ 2 万/年。
   - 用户量 > 1 万 / 对外收费：**必须**采购 Choice 或 Wind 授权，年成本 6-30 万。

## 6 · 给下游 Agent 的接力信息

- **产品形态 Agent**：自选股 Dashboard 数据源建议直接绑定 Tushare + AkShare，异动推送绑定 MiniQMT（可选）。Level-2 在 v1 不做。

- **开源框架 Agent**：MiniQMT 推荐配 `xtquant` SDK；回测推荐 `vnpy` 接 `vnpy_tushare` + `vnpy_akshare`，避免 vnpy_rqdata 的付费门槛。
- **推送通道 Agent**：异动信号源头在 AkShare 板块 + MiniQMT Tick，推送频率上限要做 1 秒级 dedup。
