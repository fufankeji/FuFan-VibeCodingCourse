Seven Claude Code skills that compose AlphaProject's testing strategy and feature workflow.

## Skills

Drop each folder under your local `.claude/skills/` to install.

### Strategy & Routing

| Skill | Purpose |
|-------|---------|
| [`skills/testing-system-blueprint/`](./skills/testing-system-blueprint/) | Build a project-wide testing system blueprint — layers, ownership, coverage targets |
| [`skills/test-routing-advisor/`](./skills/test-routing-advisor/) | Decide which layer/kind of test a given change should land in |

### Layered Testing

| Skill | Purpose |
|-------|---------|
| [`skills/backend-testing/`](./skills/backend-testing/) | Backend unit and integration testing patterns |
| [`skills/frontend-testing/`](./skills/frontend-testing/) | Frontend component and interaction testing patterns |
| [`skills/fullstack-slice-testing/`](./skills/fullstack-slice-testing/) | Vertical fullstack slice testing — exercise one feature top-to-bottom |
| [`skills/full-chain-testing/`](./skills/full-chain-testing/) | End-to-end user-journey testing (Playwright-based scaffold, demo app, scripts) |

### Feature Workflow

| Skill | Purpose |
|-------|---------|
| [`skills/run-feature/`](./skills/run-feature/) | Drive feature-by-feature development through a structured run workflow |
