支撑 AlphaProject 测试策略与特性工作流的 7 个 Claude Code 技能。

## 技能（Skills）

将每个文件夹放入本地 `.claude/skills/` 即可安装使用。

### 策略与路由

| 技能 | 用途 |
|------|------|
| [`skills/testing-system-blueprint/`](./skills/testing-system-blueprint/) | 搭建项目级测试体系蓝图 —— 分层、归属、覆盖目标 |
| [`skills/test-routing-advisor/`](./skills/test-routing-advisor/) | 判断某次变更该落在哪一层、哪种测试 |

### 分层测试

| 技能 | 用途 |
|------|------|
| [`skills/backend-testing/`](./skills/backend-testing/) | 后端单测与集成测试规范 |
| [`skills/frontend-testing/`](./skills/frontend-testing/) | 前端组件与交互测试规范 |
| [`skills/fullstack-slice-testing/`](./skills/fullstack-slice-testing/) | 纵向全栈切片测试 —— 单功能自顶到底贯通跑通 |
| [`skills/full-chain-testing/`](./skills/full-chain-testing/) | 端到端用户旅程测试（Playwright 脚手架 + demo 应用 + 脚本）|

### 特性工作流

| 技能 | 用途 |
|------|------|
| [`skills/run-feature/`](./skills/run-feature/) | 通过结构化运行流程，按特性逐个推进开发 |
